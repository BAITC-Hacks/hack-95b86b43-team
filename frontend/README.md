# Контур закупок — frontend

Рабочий интерфейс HACKALEM AI для кейса «Электрокомплект». React + TypeScript + Vite, собственные CSS-компоненты и SVG-графики. Шрифт Manrope поставляется локально; внешние CDN во время демо не нужны.

## Быстрый запуск

Рекомендуемый запуск всего проекта — `start.ps1` из корня. Backend отдаёт собранный `frontend/dist` на `http://127.0.0.1:8000/`; второй сервер для интерфейса не нужен.

После изменения frontend:

```powershell
cd frontend
npm ci
npm run build
```

Для разработки можно запустить `npm run dev`: Vite проксирует `/api` и `/health` на backend `127.0.0.1:8000`. Сначала запустите backend.

## Экраны

- **Обзор:** состояние закупок, график фактического и очищенного спроса по показательной позиции, приоритетные рекомендации.
- **Рекомендации:** фильтры склада/категории, поиск, срочность, группировка поставщиков, создание черновика заказа.
- **Карточка позиции:** численная формула, поправка по датам поставок, прогноз остатков, месячная история, сезонный профиль, клиентские события и ограничения данных.
- **Что, если?:** новый серверный расчёт с включёнными/выключенными поправками. Отображается предыдущее и новое количество, без изменения сохранённых заказов.
- **Данные:** скачивание девяти активных CSV, загрузка новых файлов и дат, ошибки валидации. Набор активируется только после успешной проверки.
- **Заказы:** редактирование количества с обязательной причиной изменения, локальное утверждение, CSV-экспорт утверждённого снимка.

## Принципы

- Все цифры и графики приходят из API. Прогнозирование в браузере не дублируется.
- Количества разных единиц измерения не суммируются; стоимость закупок не выдумывается из продажных цен.
- Дата расчёта и синтетический характер демонстрационного набора явно обозначены.
- Десятичные количества заказов отправляются строками для сохранения точности.
- Утверждение не отправляет заказ поставщику. Сохранённые заказы являются отдельными снимками расчёта.
- Интерфейс адаптирован к мобильному экрану, учитывает `prefers-reduced-motion`, содержит названия кнопок и управление карточкой с клавиатуры.

## Файлы

- `src/app/App.tsx` — состояние приложения, запуск/polling расчётов, навигация.
- `src/pages/` — экраны расчёта, рекомендаций, карточки, данных и заказов.
- `src/shared/api/client.ts` — HTTP-клиент с обработкой ошибок.
- `src/shared/types/index.ts` — контракт API.
- `src/shared/ui/` — форматирование, иконки, общие элементы и SVG-графики.
- `src/styles.css` — визуальная система и адаптивные стили.

`npm run build` проверяет строгие TypeScript-типы и создаёт production-сборку. Функциональные проверки API находятся в backend-тестах; пользовательский сценарий описан в `docs/DEMO.md` в корне проекта.
