# Локальные данные

- `uploads/` — новые неизменяемые загрузки, имена задаёт сервер.
- `exports/` — файлы утверждённых версий заказов.
- `cache/` — удаляемые производные данные; не источник истины.

Содержимое этих каталогов исключено из Git. Исходные файлы партнёра остаются в корневых `IEK/` и `Systeme electric/`; их не переименовывать и не изменять при импорте. Нормализованные записи хранятся в PostgreSQL, а не в дополнительных копиях Excel.

`samples/minimal/` — маленький версионируемый набор этапа 1. `synthetic/` — большой воспроизводимый набор этапа 2, исключённый из Git: `python -m backend.generate_synthetic`. Обе группы полностью вымышлены. Скрытый спрос и сценарии большого набора находятся только в `synthetic/metadata.json` и `synthetic/metadata/true_demand.csv`, вне входного контракта расчёта. Сырые загрузки не публикуются как статические ресурсы frontend.
