# Контракт данных

Статус: предварительная спецификация по просмотренным Excel; значения и бизнес-семантика требуют полной проверки при реализации импорта.

## Общие правила

- Код 1С и артикул — строки; сохранять нули и значимые символы. Связь с поставщиком отдельная.
- Ключ наблюдения включает товар, период/дату, склад или явно обозначенный общий контур, версию источника.
- Неизвестный склад не равен общему контуру. Общий остаток нельзя автоматически распределить по складам.
- Даты движения сохраняют исходный часовой контекст; календарная дата расчёта задана явно. Период полноты источника хранится отдельно от времени загрузки.
- Количество и ограничения партии приводятся к согласованной единице; деньги и точные пересчёты используют десятичные значения.
- Ноль, пустая ячейка и отсутствующая строка различаются до подтверждения семантики отчёта.
- Каждая запись имеет ссылку на импорт, файл, лист и строку; производная запись — на исходные записи и правило преобразования.
- Синтетические данные имеют отдельный признак и не смешиваются с реальными в одном расчёте.

## Источники

| Вид | Обязательные поля | Необязательные/пока отсутствующие | Правило |
|---|---|---|---|
| Продажи по документам | дата, документ, код 1С, количество, единица, склад | анонимный client_id, цена, явный тип операции | Согласовать знаки и типы операций; не использовать abs для всех строк |
| Месячные продажи | код 1С, месяц, количество, охват | единица, категория | Длинная история/сверка; не складывать с теми же документами |
| Остатки | код 1С, дата снимка, количество, единица, охват | резерв, свободное количество | Начальный месячный остаток не равен текущему |
| Поступления | код 1С, поставка, количество, единица, ожидаемая дата | склад назначения, статус подтверждения | Неизвестная дата не считается своевременной поставкой |
| Поставщик и товар | идентификаторы, единицы, срок поставки | MOQ, кратность, конверсия, категория | Отсутствующие условия не заменять скрытыми значениями |
| Stockout | товар, охват, начало, конец | источник подтверждения | Месячный нулевой остаток не задаёт длительность отсутствия |
| Внешний прирост | товар/категория, период, значение, смысл | автор, комментарий | Указать долю/процент/множитель и способ сочетания с трендом |
| Сезонный профиль | месяц, индекс, область действия, период построения | единица исходного агрегата | Не применять денежный профиль к штукам без проверки |

## Адаптеры

`iek.py`: шапки продаж/остатков в несколько строк; MOQ с кодом 1С и артикулом; поставки отдельными колонками с датами в заголовках. Есть бухты и метры.

`systeme.py`: динамика документов и месячные таблицы; основной `TDSheet` содержит категории, рост, сезонность, общий остаток, резерв, свободный остаток и путь. Дубли сезонных листов не загружаются повторно. Отдельный MOQ рассматривается как кандидат в основной источник ограничений после проверки конфликтов.

При конфликте источников выводить диагностику и применять только явно настроенный приоритет. Не усреднять несовместимые данные.

## Блокировки и предупреждения

Ошибка формата, неоднозначный ключ, неизвестная единица или несовместимый охват блокируют активацию затронутых строк. Отчёт импорта показывает принятые, отклонённые и предупреждённые строки. Частичное покрытие явно отражается в расчёте.

Нет client_id — доступно выявление по документу, анализ клиента недоступен. Нет stockout-интервалов — нет подтверждённой коррекции за дни отсутствия. Нет актуального остатка/срока поставки/пересчёта единиц — допускается только явно заданный демонстрационный сценарий либо статус «недостаточно данных» для заказа.

## Открытые вопросы партнёру

1. Типы операций, знаки количества, возвраты и значение пустых ячеек.
2. Актуальный снимок ИЭК и точные даты/охват всех остатков.
3. Связь общего остатка Systeme Electric с показанными складскими колонками.
4. Стабильный обезличенный client_id и интервалы stockout.
5. Сроки новых поставок, минимум заказа и кратность как разные поля.
6. Расшифровка категорий, внешнего роста и сезонных коэффициентов.
7. Правила единиц хранения/заказа и шаблон импорта заказа в 1С.
