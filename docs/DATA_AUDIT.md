это измерение аудита с двумя чтениями книг и записью JSONL, а не производительности будущего импорта в БД.

## Пропуски, ограничения и остатки

- ИЭК: 44 626 пустых месячных ячеек продаж из 81 279; 27 678 пустых остатков из 94 149.
- Systeme: 7 105 пустых месячных ячеек продаж из 18 282; 5 133 пустых остатков из 23 133.
- TDSheet: 1 581 пустая месячная ячейка из 16 401; одновременно есть 4 243 явных нуля.
  Пустота и ноль действительно различаются в исходниках.
- В MOQ ИЭК 15 сохранённых результатов формул равны `#N/A`: строки 78, 86, 89, 95, 106,
  377, 414, 415, 1222, 1223, 1280, 1316, 1510, 1795, 1810 листа `Лист7`.
  Они не становятся числовым минимумом. Среди допустимых строк есть одно повторение кода.
- В пути ИЭК строки 1496 и 2216 листа `Лист4` имеют числовой код. Они требуют проверки:
  строковые идентификаторы из чисел автоматически не восстанавливаются.
  Среди допустимых строк пути есть 7 повторений кода, в том числе 3 полностью совпадающие строки.
  Автоматическое удаление или суммирование дублей не выполнено.
- У Systeme отдельный MOQ покрывает все 554 кода месячных продаж, но кратность расходится у 26 кодов.
  В отдельном MOQ нет пустых/неположительных ограничений. Приоритет должен быть явным.
- Только 469 из 497 кодов TDSheet встречаются в MOQ и месячных продажах. Для 28 кодов
  соответствие отсутствует. У ИЭК 710 кодов месячных продаж не имеют допустимой строки MOQ.
- Для всех 497 строк TDSheet выполнено `остаток − резерв = свободный остаток`.
  Сумма четырёх видимых складских колонок не равна общему остатку в 493 строках из 497.
  Складской фильтр по этим данным пока необоснован.
- В TDSheet 289 отрицательных коэффициентов роста и 274 отрицательных коэффициента сезонности.
  Отрицательный сезонный коэффициент нельзя непосредственно умножать на спрос как сезонный индекс.
- В месячных остатках ИЭК есть 5 отрицательных значений. Они не заменяются нулём.

Полностью совпало содержимое сезонных листов в месячных продажах Systeme и в книге пути,
несмотря на разный заявленный размер листа. Отдельная книга сезонности отличается формулами/ячейками;
равенство всех трёх листов не утверждается. Ни один сезонный лист пока не применяется к количественному прогнозу.

## Источники первого сценария

Сценарий явно выбирает TDSheet для истории и свободного остатка, отдельный MOQ — для кратности.
Динамика и месячный отчёт остаются независимыми источниками для сверки и дальнейшей реализации.
Путь хранится со своим заголовком; дата 24.09.2026 и подтверждённость поставки в расчёте — явные допущения сценария.
Не подтверждены дата снимка, общий охват, единицы и политика закупки.

Запуск `preview-systeme` с предоставленной политикой даёт 497 строк:
408 рассчитаны в рамках сценария, 89 имеют статус `insufficient_data`.
Из них 88 заблокированы отрицательными продажами в одном из последних шести полных месяцев,
одна — неизвестным значением марта 2026. Результат не является утверждённым заказом.
Нулевая потребность может быть рассчитана и при неизвестной кратности; положительный заказ — нет.
