# API локального MVP

Актуальная машинная схема генерируется FastAPI: `/docs` и `/openapi.json`. Рабочий префикс — **/api**, без `v1`. Маршруты из раннего проекта промышленной архитектуры не считаются реализованными.

## Маршруты

| Метод и путь | Назначение |
|---|---|
| GET `/health` | Статус и версия процесса |
| GET `/api/bootstrap` | Активный набор, справочники, последние расчёты и заказы |
| POST `/api/datasets` | Проверить и активировать канонический CSV-набор |
| GET `/api/datasets/current/download` | ZIP девяти входных CSV активного набора |
| POST `/api/calculations` | Поставить расчёт в локальную очередь; 202 с run_id |
| GET `/api/calculations/{run_id}` | Состояние, прогресс и готовый результат |
| GET `/api/preprocessing/summary` | Сводка подготовки из последнего завершённого расчёта |
| GET `/api/orders` | Сохранённые заказы в поле items |
| POST `/api/orders` | Черновик для одного поставщика на основании расчёта |
| GET `/api/orders/{order_id}` | Заказ, версия, строки и аудит |
| PATCH `/api/orders/{order_id}` | Изменить строки черновика с проверкой версии |
| POST `/api/orders/{order_id}/approve` | Утвердить текущую версию |
| GET `/api/orders/{order_id}/export` | Скачать CSV утверждённого заказа |

Метода отправки поставщику нет.

## Импорт

JSON-запрос содержит:

- `label` — название набора.
- `history_start`, `history_end`, `as_of_date` — даты YYYY-MM-DD.
- `files` — объект из ровно девяти пар: каноническое имя CSV → его текст.

Поддерживаемые имена: products.csv, categories.csv, warehouses.csv, suppliers.csv, product_suppliers.csv, sales.csv, inventory.csv, stockouts.csv, inbound.csv. Суммарный UTF-8 размер содержимого ограничен 25 МБ. Это ограничение локального API, а не потоковый загрузчик больших промышленных выгрузок.

Период истории заканчивается за день до даты снимка остатка. Ошибочный набор возвращает `valid: false` и структурированный `report`, не заменяя текущие данные. При успешной загрузке — `valid: true`, публичный манифест и отчёт. HTTP 200 у импорта сам по себе не означает валидность: проверяйте поле `valid`.

## Расчёт

Поля запроса:

| Поле | Значение по умолчанию |
|---|---|
| warehouse_id | null — все склады |
| category_id | null — все категории |
| review_days | 7 |
| safety_days | 5 |
| use_stockout | true |
| use_outliers | true |
| use_seasonality | true |
| use_trend | true |

Диапазоны и обязательность типов указаны в OpenAPI. Сценарные переключатели реально меняют входы прогноза. Выключенная коррекция не объявляется рекомендацией для рабочего использования.

Ответ постановки — `run_id` и `status`. Далее опрашивайте GET расчёта. Состояния: queued, running, completed, failed. У завершённого расчёта есть `result` с `recommendations`, `summary`, данными источника и отчётом подготовки. При failed отображайте безопасное сообщение об ошибке.

Рекомендация содержит идентификатор, SKU, склад, категорию, поставщика, количество, единицу, срочность, компоненты потребности, объяснение, историю, будущую проекцию, события, поставки и предупреждения. Не пересчитывайте количество на frontend.

Срочность: critical, review, order_now, reserve, none. Critical означает риск до прибытия обычной новой поставки и требует отдельного решения менеджера.

## Заказы

Создание принимает `run_id`, `supplier_id`, `lines`. Каждая строка содержит `recommendation_id`, `quantity` и `reason`. Все строки должны принадлежать выбранному поставщику и быть уникальными.

При отклонении от рекомендации обязательна содержательная причина. Положительное количество проверяется на MOQ и кратность. Нулевая строка означает отказ от закупки этой позиции; заказ с полностью нулевыми строками нельзя утвердить.

Правка принимает `expected_version` и полный новый список строк. Утверждение принимает `expected_version`. Устаревшая версия или изменение уже утверждённого заказа получает 409. Повторное создание для одной пары расчёт/поставщик возвращает существующий документ; для новой версии после утверждения нужен новый расчёт.

Экспорт возвращает UTF-8 CSV с BOM и разделителем `;`. Столбцы: order_id, supplier_id, sku, warehouse_id, unit, quantity, recommended_qty, reason, approved_at. Включены положительные утверждённые строки. При открытии через Excel импортируйте SKU как текст: автоматическое определение типа при двойном щелчке может удалить ведущие нули, хотя они сохранены в CSV.

## Ошибки и безопасность

- 404 — расчёт или заказ не найден.
- 409 — конфликт версии/состояния.
- 413 — превышен размер CSV-набора.
- 422 — неверные параметры или бизнес-ограничения.
- Ошибки отдельных строк импорта находятся в ValidationReport.

Это локальный API без аутентификации. Не выставляйте его в общую сеть без отдельной доработки доступа. Клиентские идентификаторы во входах должны быть обезличены. Известные текстовые формулы при CSV-экспорте экранируются для безопасного просмотра в табличных редакторах.
