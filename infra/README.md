# Окружение запуска

Статус: корневой `compose.yaml` запускает PostgreSQL 17 с постоянным томом и healthcheck.
Порт доступен только на 127.0.0.1 (по умолчанию 5433). Пароль задаётся в корневом `.env`.
API, worker и frontend пока не контейнеризированы. Инструкция — `docs/POSTGRES_IMPORT.md`.

Планируемые процессы:

| Процесс | Назначение |
|---|---|
| frontend | Интерфейс менеджера; локальный Vite при разработке |
| api | FastAPI, проверки запросов, сценарии и доступ к результатам |
| worker | Один исполнитель импорта, расчёта и экспорта из того же backend-пакета |
| postgres | Версии источников, данные, задания, рекомендации, заказы и аудит |

API и worker используют общую PostgreSQL и согласованное файловое хранилище. При контейнеризации загрузки/экспорт и база получают постоянные тома. Для локальной разработки образец настроек находится в корневом `.env.example`; переменные должны явно передаваться каждому процессу. Vite получает только публичный URL API, а не параметры базы.

После появления приложений добавить Dockerfile для backend/frontend и процессы в существующий `compose.yaml`.
Миграции импорта проверены на PostgreSQL; восстановление заданий предстоит проверить после реализации worker.
Секреты и реальные учётные записи не помещать в Git или frontend-сборку.
